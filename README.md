# タイマー＋(タイマープラス)　v1.0.0
## 制作者:HAIsan

## 概要
図形の種類「タイマー＋」を追加するプラグインです  
※exo出力には対応していません  
※既存のタイマーとの置き換えはないため既存のタイマーとタイマー＋を別で利用できます  

## 使用方法
図形の種類に「タイマー＋」が追加されます  
書式をカスタムにすることでオリジナル書式のタイマーを配置できます  
  
使用カテゴリ:各単位の使用するトグルをONにしてください  
  
前文字:数値の前につける文字です  
後文字:数値の後ろにつける文字です  
※どちらも制御タグが利用できます  
  
桁数:桁数を設定できます  
※1、例:3桁に設定した場合2桁以下でも099などと表記されます  
※2、例:3桁に設定した場合4桁以上になると自動で1000と桁が増えます  
表示行:表示する行を変更できます  
桁数固定:桁数※2の自動で桁が増えるのを防ぎ3桁で必ず固定されるようにできます  
  
個別設定:単位ごとのフォントやX,Y,回転角,サイズ,文字間隔,色,装飾,太字,イタリック,下線,打ち消し線を設定できます  
  
また書式カスタムではない状態のテキスト設定欄にも下線,打ち消し線が追加されています
